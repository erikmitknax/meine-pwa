# Kippen-Tracker (Sync) als Android-App

`kippen-tracker.apk` ist eine kleine WebView-Hülle, die dieselbe Seite wie
`kippen-sync-pwa/` aus ihren eigenen Dateien lädt (läuft offline, startet leer).
Updates der Seite kommen **nicht** automatisch an: Für Änderungen an der Seite
muss die APK neu gebaut werden. Wer das nicht will, nutzt die Web-App und installiert sie über den Browser.

Installation: APK aufs Handy laden, antippen, "Unbekannte Apps installieren" erlauben.
Einrichtung von Firebase siehe `../kippen-sync-pwa/README.md`.
